# Day 34 — Election Information Portal  
Republic of the Congo (2026 Presidential Election Edition)

A neutral, browser-based civic technology tool that helps voters explore and compare presidential candidates in the Republic of the Congo ahead of the 15 March 2026 election. The portal is designed to improve access to verified public information and support informed, peaceful participation in the democratic process.

This project is part of the **90 Days of African Solutions Challenge**, focused on building practical digital tools for real-world challenges using simple, accessible web technologies.

---

## Purpose

In many communities, voters struggle to find clear, centralized, and easy-to-understand information about who is running for office and what they stand for. Information is often scattered across social media, news sites, and official documents that are not always accessible on low-end devices.

This portal provides a lightweight, neutral interface where users can:
- Select a candidate
- View their party affiliation
- Read a short background summary
- Understand their stated focus areas and priorities

The goal is not to influence political choice, but to improve access to factual, structured civic information.

---

## Tech Stack

- HTML  
- CSS  
- Vanilla JavaScript  

No frameworks, build tools, or server dependencies required.

---

## Features

- Candidate selection dropdown  
- Clean and readable candidate profile display  
- Mobile-friendly, responsive layout  
- Offline-friendly after initial load  
- Easy-to-update data structure for new candidates or elections  
- Neutral and non-partisan presentation
